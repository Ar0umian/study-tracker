# 📚 متتبع المذاكرة والمراجعة

تطبيق ويب عربي (RTL) لإدارة خطة المذاكرة والمراجعة بالتكرار المتباعد وتنظيم المواد والشباتر والدروس، مع حفظ محلي ومزامنة سحابية عبر Firebase.

## 🔗 رابط الموقع

**[https://ar0umian.github.io/study-tracker/](https://ar0umian.github.io/study-tracker/)**

---

## ✨ المميزات

- **لوحة اليوم:** عرض المهام والمراجعات المجدولة لليوم مع إمكانية التأكيد، و**تعويض يوم فائت**، و**تراجع عن آخر تأكيد**.
- **إدارة المواد والشباتر والدروس:** استيراد دفعي عبر `.txt` أو `.json` أو لصق مباشر (يدعم أكثر من مادة، الإيقاع الأسبوعي، ومدة الدراسة)، مع معاينة قبل تأكيد الإضافة.
- **تقويم شهري وأسبوعي:** استعراض حالة الأيام وتفاصيل مهام أي يوم محدد.
- **إعدادات الخطة والتكرار المتباعد:** ضبط تاريخ البداية، أيام المراجعة القريبة، نافذة التحضير القادم، سقف المراجعة البعيدة اليومية وحصة السبت، وفواصل التقييم الأولى ومعامل السهولة.
- **الحساب والمزامنة السحابية:** تسجيل الدخول (Google أو البريد الإلكتروني وكلمة المرور) ومزامنة البيانات مع Firestore ضمن مجموعة مستقلة لكل مستخدم (`study_users/{uid}`).
- **نسخ احتياطي محلي:** تصدير واستيراد البيانات بصيغة JSON، مع خيار مسح البيانات.

## 📅 الجدول الأسبوعي

| اليوم | المهام |
|---|---|
| الأحد – الخميس | مهام المذاكرة والمراجعة المجدولة |
| الجمعة 🌿 | إجازة خفيفة |
| السبت 🔄 | مراجعة أسبوعية بحصة مخصصة |

## 🧮 منطق التكرار المتباعد والمراجعة

- **المراجعة القريبة:** تغطي آخر الأيام الدراسية المحددة في الإعدادات.
- **المراجعة البعيدة والتكرار المتباعد:** تعتمد على تقييمك لكل درس وفواصل التقييم الأولى (`صعب`، `جيد`، `سهل`) ومعامل السهولة الافتراضي، ضمن السقف اليومي المحدد وحصة السبت.

## 🚀 طريقة الاستخدام

1. افتحي [رابط الموقع](https://ar0umian.github.io/study-tracker/).
2. من **الإعدادات** حدّدي إعدادات الخطة والتكرار المتباعد، ثم أضيفي المواد والشباتر والدروس من تبويب **المواد** (أو استورديها دفعة واحدة).
3. تابعي مهامك اليومية من تبويب **اليوم** وأكّدي إنجازها أولاً بأول.

## 💾 البيانات والخصوصية

- تُحفظ البيانات محلياً في `localStorage` داخل متصفحك (`studyTrackerV1`)، ويمكن ربطها بحسابك لمزامنتها سحابياً في Firestore (`study_users/{uid}`).
- يُنصح بأخذ نسخة احتياطية دورية عبر **تصدير JSON** من الإعدادات قبل أي تغييرات كبيرة أو عند الانتقال بين الأجهزة.

## 🛠️ التشغيل محلياً

لا يحتاج أي تثبيت. حمّلي الملف `index.html` وافتحيه في المتصفح مباشرة.

HTML + CSS + JavaScript (Vanilla) مع تكامل Firebase Authentication وCloud Firestore.
